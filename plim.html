Entenda sobre Html

Html é uma linguagem básica da programação, composta por corpo (body) e cabeça (head) onde a cabeça é responsavel pelos olhos, ou seja, seção da página e pelos metadados, aqueles que conversam com o navegador, determinando qual tipo de dado o html sera transmitido e palavras chave de busca para página

HTML, Java Script e Css, são as ferramentas mais comumente usadas para criar sites.


Então :

  • O html fornece estrutura
  • O CSS inclui layout, cores e fontes
  • O java interativa a pagina, tornando ela mais envolvente

Resumindo:

  1. HTML: estrutura, conteudo e marcação,
  2. CSS: apresentação, estilo e formatação
  3. Java: Interatividade, funcionalidade e comportamento

Tabela em HTML:
código significado
< tr > usada no inicio e no final de uma linha
< th > usadas no inicio e no final para indicar células em negrito
< td > usadas no inicio e no final para indicar céluas normais

Agora observe a ordem dos códigos em uma tabela em bordas:
código quando usar
< tr > primeiro abro ele
< th> celuas em negrito, onde a priemeira tag sera contada da esquerda pra direita (como se fosse a célula A1) , que nem no excel, logo a segunda será classificada como a A2 no excel, só muda de linha quando fecho o "tr"
< td > células padões com a mesma linha de A1 e A2
